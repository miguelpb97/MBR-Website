Qué hacemos

Servicios especializados

Coding Mercedes

Activación de funciones ocultas, personalización y adaptaciones mediante coding SCN oficial para Mercedes-Benz. Compatible con modelos desde 2010.

Retrofits

Instalación y coding de equipamiento original Mercedes-Benz: CarPlay, pantallas MBUX, cámara 360°, sistemas de asistencia, luces largas adaptativas y mucho más.

Diagnóstico

Diagnóstico profesional con Xentry DAS para Mercedes-Benz: lectura y borrado de fallos, adaptaciones, actualizaciones SCN y valores reales en tiempo real.
